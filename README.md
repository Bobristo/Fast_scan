Высокоточный асинхронный сканер TCP-портов на Rust с автоматической адаптацией под сетевые задержки и интеграцией с Nmap.

## Особенности

- ⚡ **Высокая скорость:** Асинхронная обработка I/O на базе `tokio`.
- 🎯 **3-фазная точность:**
  1. *Основное сканирование:* Быстрый рандомизированный проход по всем портам.
  2. *Smart Retries:* Повторная проверка спорных/неответивших портов с повышенным таймаутом.
  3. *Validation:* Трехкратное подтверждение открытых сокетов.
- ⚙️ **Динамический RTT:** Автоматический расчет сетевых таймаутов под нестабильные VPN-каналы (HTB / TryHackMe / OffSec).
- 🛡️ **Контроль ресурсов:** Управление системными лимитами `NOFILE` (`getrlimit`/`setrlimit`) и защита от исчерпания временных портов Linux.
- 🔌 **Интеграция с Nmap:** Автоматическая передача найденных портов в Nmap для сканирования версий сервисов и скриптов.

## Установка


git clone [https://github.com/Bobristo/Fast_scan.git](https://github.com/Bobristo/Fast_scan.git)
cd Fast_scan
cargo install --path .


## Использование 
# Быстрый сканинг всех 65535 портов и передача результатов в Nmap
fast_scan 10.129.244.174 -n

# Сканирование определенного диапазона портов с записью в JSON
fast_scan 10.129.244.174 -p 1-1024 -o results.json

# Передача кастомных флагов в Nmap
fast_scan 10.129.244.174 -n -A "-sV -sC -O -Pn"
